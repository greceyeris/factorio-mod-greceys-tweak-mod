### 简体中文

### 简介

Grecey 的 Factorio 2.1 可配置调整模组.

本模组提供世界, 资源, 角色, 实体, 物品, 装备, 配方, 科技, 成就, 快捷方式和实用功能等多方面的调整. 大部分功能均可通过启动设置单独启用或关闭.

### 依赖

- Factorio 2.1.x.
- Grecey 的库模组.

### 兼容性

本模组针对 Factorio 2.1.x 开发.

可选兼容功能仅在对应模组启用时加载.

### 基础功能

**世界**

- 在游戏开始时启用终为白日模式.
- 在游戏开始时移除坠机现场, 默认初始物品和坠机残骸中的物品.
- 移除新生成区块中的装饰物.

**资源**

- 添加可像原油一样开采的地下水资源.
- 使可重复开采的资源保持无限, 并维持 100% 的开采产量.

**角色**

- 在游戏开始时清空角色的所有库存和装备.
- 在游戏开始时给予热能采矿机.
- 在游戏开始时给予建设套装.
- 在游戏开始时给予武器和弹药.
- 调整角色制造速度.
- 调整角色生命值恢复速度.
- 调整角色建造, 常规交互和资源交互距离.
- 调整角色最大生命值.
- 调整角色采矿速度.
- 调整角色重生速度.
- 调整角色移动速度.

**实体**

- 添加使用电力运行的原版石炉和原版钢炉.
- 为所有电线杆添加免费照明效果.
- 允许抽水泵放置在原本没有流体属性的地块上.
- 移除流体管线范围限制.
- 添加用于持续销毁物品的虚空箱.
- 添加用于持续销毁流体的虚空管.
- 允许具有输入和输出槽的熔炉手动选择配方.
- 为采矿机添加物品过滤功能.
- 禁止机械臂向机器输入槽放入过量原料.
- 允许具有插件槽的机器使用所有插件类别和插件效果.
- 调整机械臂的旋转速度和伸缩速度.
- 调整物流机器人和建造机器人的移动速度.
- 调整传送带, 地下传送带, 分流器, 装卸机和类似实体的运行速度.

**物品**

- 添加用于在陆地上放置水面的造水料.
- 调整可堆叠物品的堆叠数量.

**装备**

- 将所有装备的装备网格占用大小调整为 `1 x 1`.

**配方**

- 允许所有配方使用所有插件类别和插件效果.
- 始终显示能够制造该配方的机器.

**科技**

- 在游戏开始时自动研究前 5 级工作机器人速度科技.
- 显示并启用所有隐藏科技.
- 移除已经通过递归前置关系满足的冗余科技前置.

**成就**

- 移除受限制成就的限制条件.

**快捷方式**

- 在游戏开始时自动启用 ALT 模式.

**实用功能**

- 显示地下传送带和地下管道的最远连接位置.

### 可选模组功能

#### 质量模组

**配方**

- 允许所有配方选择品质.

#### 回收机模组

**配方**

- 移除所有回收配方.

#### 太空时代模组

**实体**

- 移除机器冻结.

**物品**

- 移除物品变质.

## English

### Overview

A configurable tweak mod for Factorio 2.1 by Grecey.

The mod provides adjustments for worlds, resources, characters, entities, items, equipment, recipes, technologies, achievements, shortcuts, and utilities. Most features can be enabled or disabled independently through startup settings.

### Requirements

- Factorio 2.1.x.
- Grecey's Library Mod.

### Compatibility

This mod is developed for Factorio 2.1.x.

Optional compatibility features are loaded only when their corresponding mods are enabled.

### Basic Features

**World**

- Enables always-day mode at game start.
- Removes the crash site, default starting items, and items contained in crash-site debris at game start.
- Removes decorations from newly generated chunks.

**Resources**

- Adds ground water as a resource that can be extracted like crude oil.
- Makes repeatedly mineable resources infinite while maintaining a 100% mining yield.

**Characters**

- Clears all of the character's inventories and equipment at game start.
- Gives burner mining drills at game start.
- Gives a construction kit at game start.
- Gives weapons and ammunition at game start.
- Adjusts character crafting speed.
- Adjusts character health regeneration speed.
- Adjusts character building, general interaction, and resource interaction distances.
- Adjusts character maximum health.
- Adjusts character mining speed.
- Adjusts character respawn speed.
- Adjusts character running speed.

**Entities**

- Adds vanilla stone and steel furnaces powered by electricity.
- Adds free lighting effects to all electric poles.
- Allows offshore pumps to be placed on tiles without an original fluid property.
- Removes fluid pipeline extent limits.
- Adds void chests that continuously destroy items.
- Adds void pipes that continuously destroy fluids.
- Allows furnaces with input and output slots to select recipes manually.
- Adds item filtering support to mining drills.
- Prevents inserters from loading excess ingredients into machine input slots.
- Allows machines with module slots to use all module categories and module effects.
- Adjusts inserter rotation and extension speeds.
- Adjusts logistic and construction robot movement speeds.
- Adjusts the speeds of transport belts, underground belts, splitters, loaders, and similar entities.

**Items**

- Adds waterfill for placing water tiles on land.
- Adjusts stack sizes for stackable items.

**Equipment**

- Changes all equipment grid occupancy sizes to `1 x 1`.

**Recipes**

- Allows all recipes to use all module categories and module effects.
- Always displays the machines that can craft each recipe.

**Technologies**

- Automatically researches the first 5 worker robot speed technologies at game start.
- Displays and enables all hidden technologies.
- Removes redundant technology prerequisites that are already satisfied recursively.

**Achievements**

- Removes restrictions from restricted achievements.

**Shortcuts**

- Automatically enables ALT mode at game start.

**Utilities**

- Displays the farthest connection position for underground belts and underground pipes.

### Optional Mod Features

#### Quality Mod

**Recipes**

- Allows quality selection for all recipes.

#### Recycler Mod

**Recipes**

- Removes all recycling recipes.

#### Space Age Mod

**Entities**

- Removes machine freezing.

**Items**

- Removes item spoilage.
